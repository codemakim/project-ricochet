# 전투 밀도·보스 압박 보정 설계

## 배경

플레이테스트에서 최초 편성은 긴장감이 있었지만, 영구 구슬이 약 3개가 된 뒤부터 3스테이지 전까지 적 공급과 체력이 화력을 따라오지 못했다. 화면에 적이 두 줄 이상 유지되는 경우가 드물었고 사격 적도 적었다. 1보스의 좌우 약점은 너무 작아 조준 의욕을 떨어뜨렸으며, 2보스는 코어만 남아도 고정되어 있고 격노 공격도 정적인 인상을 줬다. 보조 효과 강화는 충분히 체감됐다.

현재 설정과 체감은 일치한다. 1스테이지 증원은 8~12칸, 활성 상한 24, 간격 9초, 일반 HP 배율 1.0으로 시작한다. 사격 적은 첫 페이즈 가중치와 최대 수가 모두 0이다. 1보스 약점은 시각 18×48, 판정 22×52다. 2보스 코어 위치는 x=225로 고정이고 격노 패턴은 확산탄 2.8초, 조준탄 1.6초 간격이다.

## 목표

- 최초 편성의 긴장감은 유지한다.
- 1스테이지 중반부터 강한 빌드에서도 화면에 적 2~3줄이 대체로 유지되게 한다.
- 적 하강 속도를 올리지 않고 공급량과 HP로 압박을 만든다.
- 1·2스테이지의 사격 적을 더 자주 보이게 한다.
- 1보스 약점은 눈에 보이고 노릴 만한 크기로 만든다.
- 2보스 코어 단독 상태는 이동과 공격량 모두 격노로 느껴지게 한다.
- 구현 뒤 밸런스 재조정은 설정표만 바꿔 가능하게 한다.

## 범위 밖

- 구슬, 융합, 능력, 보상 출현 규칙 변경
- 최초 편성 변경
- 적 하강 속도 변경
- 3스테이지 난이도 변경
- 신규 적, 보스 패턴, 그래픽, 사운드 추가
- 플레이어 화력에 따른 동적 난이도 보정

## 튜닝 책임

설정 위치는 두 곳으로 제한한다.

- `src/game/encounters/stageDefinitions.ts`
  - 스테이지·페이즈별 HP 배율
  - 활성 적 상한
  - 증원 간격
  - 증원 진입 허용 위치
  - 사격 적 가중치와 페이즈당 최대 수
- `src/game/config/gameTuning.ts`
  - 적 공통 기본 수치
  - 1보스 약점 크기
  - 2보스 코어 이동 범위·속도·맥동
  - 2보스 격노 패턴 간격·탄 수·전용 탄환 상한

`docs/TUNING.md`에는 체감별 수정 위치를 색인으로 기록한다. 로직 파일에는 새 밸런스 숫자를 넣지 않는다.

## 적 밀도와 파워 곡선

### 공통 규칙

- 최초 편성은 현재 데이터와 생성 규칙을 그대로 사용한다.
- 적 하강 속도는 `8px/s`를 유지한다.
- 편성의 셀 수, 행 수, 통로 마스크는 유지한다.
- 한 편성을 더 크게 만드는 대신 여러 편성이 겹쳐 진입하게 해 2~3줄을 만든다.
- `StagePhaseDefinition`에 `reinforcementReleaseY`를 추가한다. `EncounterDirector`는 전역 값 대신 현재 페이즈의 값을 읽는다.
- 활성 상한은 약한 빌드에 무조건 적을 추가하는 목표치가 아니라, 빠르게 적을 제거한 강한 빌드에 다음 편성을 허용하는 상한이다.

### 스테이지별 HP

| 스테이지 | 일반 HP 배율 | 대형·엘리트 HP 배율 |
| --- | ---: | ---: |
| 1 | 1.0 → 1.3 | 1.0 → 1.5 |
| 2 | 1.6 → 1.9 | 1.8 → 2.2 |
| 3 | 2.4 유지 | 2.8 유지 |

최초 편성은 별도 초기 프로필을 사용하므로 위 1스테이지 배율 변경의 영향을 받지 않는다.

### 페이즈별 공급

| 구간 | 활성 상한 | 증원 간격 | `reinforcementReleaseY` | 사격 적 가중치 | 사격 적 최대 수 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1-초반 | 24 → 28 | 9000 → 8000ms | 50 | 0 → 1 | 0 → 1 |
| 1-중반 | 30 → 40 | 8000 → 5500ms | 50 → 0 | 1 → 3 | 1 → 2 |
| 1-후반 | 36 → 48 | 7000 → 5000ms | 50 → 0 | 2 → 4 | 2 → 3 |
| 2-초반 | 36 → 48 | 6000 → 5000ms | 50 → 0 | 2 → 4 | 2 → 3 |
| 2-후반 | 44 → 56 | 5500 → 4500ms | 50 → 0 | 3 → 5 | 3 → 4 |

3스테이지의 활성 상한, 증원 간격, HP, 사격 적 비율은 유지하고 모든 페이즈의 `reinforcementReleaseY`를 현재 동작과 같은 50으로 명시한다.

## 1보스 약점

| 항목 | 현재 | 변경 |
| --- | ---: | ---: |
| 약점 시각 크기 | 18×48 | 30×64 |
| 약점 판정 크기 | 22×52 | 38×72 |
| 몸체와 시각 겹침 | 5 | 12 |
| 약점 HP | 14 | 유지 |
| 이동 최대 속도 | 35 | 유지 |

겹침 값을 함께 키워 약점 중심이 현재 위치와 거의 같게 유지되도록 한다. 판정은 시각보다 사방으로 조금 넓어 조준 피로를 줄인다. 몸체 반사와 약점 우선 충돌 규칙은 유지한다.

## 2보스 코어 단독 격노

### 이동

- 네 구조물이 모두 파괴되어 `permanentlyExposed`가 된 순간부터 코어가 이동한다.
- 이동 범위는 x=110~340, 속도는 42px/s다.
- 기존 `updateBossMotion()`과 장애물 구간 계산 방식을 재사용한다.
- 남아 있는 일반 적이 이동 경로를 막으면 빈 구간 안에서만 이동한다. 적이 제거되면 사용 가능한 이동 범위가 넓어진다.
- `HiveBossManagerOptions`에 기존 적 스냅샷 조회 콜백을 연결한다.
- 구조물이 남아 있는 `shielded`, `telegraph`, `exposed`에서는 코어가 현재 x=225를 유지한다.
- 코어 경고 표시, 확산탄, 조준탄의 발사 원점, 디버그 스냅샷은 고정 지오메트리가 아니라 현재 코어 위치를 사용한다.

### 공격과 연출

| 항목 | 현재 | 변경 |
| --- | ---: | ---: |
| 확산탄 간격 | 2800ms | 2200ms |
| 확산탄 수 | 9 | 유지 |
| 조준탄 간격 | 1600ms | 1100ms |
| 조준탄 수 | 3 | 4 |
| 조준탄 확산각 | 18° | 유지 |
| 격노 전용 적 탄환 상한 | 공통 12 | 16 |
| 코어 맥동 크기 | 5% | 10% |

격노가 아닌 상태는 공통 적 탄환 상한 12를 유지한다. 맥동 주기는 현재 160ms를 설정값으로 옮겨 유지한다. 새 공격 패턴은 추가하지 않는다.

## 데이터 흐름

1. `EncounterDirector`가 현재 스테이지와 페이즈 데이터를 읽는다.
2. 증원 간격, 활성 상한, 페이즈별 진입 Y를 모두 만족하면 기존 편성 생성기를 호출한다.
3. 편성 생성기는 기존 그리드·통로·HP 계산을 그대로 사용하고 변경된 스테이지 HP 배율만 적용한다.
4. 2보스는 현재 페이즈를 갱신한 뒤 `permanentlyExposed`일 때만 코어 이동을 갱신한다.
5. 경고와 발사 함수는 현재 코어 스프라이트 좌표를 원점으로 사용한다.

## 검증과 오류 처리

### 설정 검증

- `reinforcementReleaseY`는 유한수여야 한다.
- 모든 활성 상한과 사격 적 최대 수는 양의 정수 또는 명시적으로 허용된 0이어야 한다.
- 격노 이동 범위는 좌우 순서가 올바르고 코어 판정이 화면 안에 들어와야 한다.
- 격노 속도, 공격 간격, 탄 수, 탄환 상한, 맥동 주기는 양수여야 한다.

### 단위 테스트

- 승인된 스테이지별 HP·상한·간격·진입 Y·사격 적 값을 고정한다.
- 같은 적 상태에서도 페이즈의 `reinforcementReleaseY`에 따라 증원 허용 결과가 달라짐을 검증한다.
- 최초 편성, 하강 속도, 3스테이지 값이 유지됨을 검증한다.
- 1보스 약점의 시각·판정 크기와 약점 우선 충돌을 검증한다.
- 2보스 코어가 구조물 생존 중에는 고정되고 단독 상태에서만 이동함을 검증한다.
- 일반 적 장애물이 코어 이동 범위를 제한하고 제거 뒤 확장됨을 검증한다.
- 이동 중 경고와 실제 탄환 원점이 현재 코어 위치를 사용함을 검증한다.
- 격노 전용 탄환 상한과 승인된 공격 수치를 검증한다.

### 브라우저 검증

- 작업 중에는 관련 집중 E2E만 실행한다.
- 완료 직전에 전체 단위 테스트, 빌드, 전체 E2E를 각각 한 번 실행한다.
- 실플레이에서는 1스테이지 중반의 화면 2~3줄 유지, 1보스 조준 피로, 2보스 코어 이동·격노 압박을 우선 확인한다.

## 후속 조정 순서

적이 과도하면 HP부터 낮추지 않는다. 다음 순서로 조정한다.

1. 활성 상한
2. `reinforcementReleaseY`
3. 증원 간격
4. 사격 적 가중치·최대 수
5. HP 배율

보스가 과도하면 격노 탄환 상한, 공격 간격, 이동 속도 순으로 조정한다. 모든 후속 조정은 두 설정표에서 끝나야 한다.
