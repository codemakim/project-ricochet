# Project Ricochet 구슬 수집·개별 강화·융합 리디자인

## 1. 목적

이 문서는 런의 초반이 구슬 1~2개로 오래 이어지고, 기존 코어 강화가 수치 성장에 머무르며, 반복 플레이에서 새 구슬을 발견할 이유가 약한 문제를 해결한다.

핵심 목표는 다음과 같다.

- 한 개로 시작하되 첫 보스 전에 구슬 3개를 보장한다.
- 구슬을 각각 얻고 키우는 수집 감각을 만든다.
- 두 구슬을 소비해 이름, 외형과 전투 방식이 달라지는 새 구슬을 만든다.
- 미발견 구슬과 융합 레시피가 다음 런의 목표가 되게 한다.
- 일반 레벨업, 구슬 보급과 보스 보상의 역할을 분리한다.
- 보상 화면의 개발용 수치 표현과 긴 설명을 제거한다.

## 2. 기존 설계와의 관계

이 문서는 다음 기존 규칙을 대체한다.

- `2026-07-27-run-build-system-redesign.md`의 시작 영구 구슬 3개와 코어 4종
- 같은 문서의 일반 능력 `추가 코어`를 통한 구슬 수 증가
- `2026-07-27-meta-progression-monetization-design.md`의 시작 구슬 3개 구성
- 해금되지 않은 코어의 이름과 성능을 처음부터 모두 공개하는 규칙

충돌하지 않는 일반 능력, 발동 제한, 무료 재화, 광고, 전장과 보스 보상 규칙은 유지한다.

## 3. 제품 원칙

### 3.1 물리적 구슬이 성장 단위다

구슬 종류별 공유 레벨을 사용하지 않는다. 같은 전도 구슬 세 개도 서로 다른 레벨을 가질 수 있다.

```text
전도 Lv4
전도 Lv2
전도 Lv1
```

강화는 선택한 구슬 하나에만 적용한다. 이 규칙으로 같은 종류를 여러 개 모았을 때 강화 카드 하나의 가치가 구슬 수만큼 폭증하는 문제를 막는다.

### 3.2 합성은 효과 병렬 부착이 아니다

합성 결과는 두 재료 효과를 그대로 나란히 가진 구슬이 아니다. 재료의 전투 원리를 재해석한 새로운 무기다.

- 전도: 전기가 아니라 에너지 전달과 대상 연결
- 관성: 속도, 직선 궤적과 축적
- 분열: 복제, 산개와 다중 타격
- 부식: 잔류, 중첩과 시간에 따른 악화
- 반향: 벽 반사, 저장과 방출
- 폭발: 확률, 범위와 순간 출력

합성 구슬은 고유 이름, 실루엣, 궤적, 충돌 이펙트와 전투 동작을 가진다. 재료의 색과 속성을 반드시 유지하지 않는다.

### 3.3 초월 합성은 보류한다

세 구슬 합성이나 합성 구슬끼리의 추가 합성은 만들지 않는다. 기본 구슬과 2구슬 융합 풀이 실제 플레이에서 충분히 재미있는지 먼저 검증한다.

## 4. 구슬 슬롯과 개별 레벨

- 활성 구슬 슬롯은 최대 6개다.
- 런은 구슬 1개로 시작한다.
- 같은 기본 구슬을 여러 개 가질 수 있다.
- 새 기본 구슬은 항상 Lv1로 추가된다.
- 기본 구슬은 각각 독립된 ID와 레벨을 가진다.
- 기본 구슬 최대 레벨은 Lv5다.
- 합성 구슬 최대 레벨은 Lv9다.
- 기본 구슬과 합성 구슬 모두 슬롯 하나를 사용한다.

기본 데이터는 구슬 인스턴스의 정체성과 레벨만 소유한다.

```ts
interface RunOrb {
  id: string;
  type: BasicOrbType | FusionOrbType;
  level: number;
}
```

합성 재료의 런타임 효과를 합성 뒤에도 별도 모듈로 보존하지 않는다. 합성 결과는 자신의 정의와 레벨만 사용한다.

## 5. 기본 구슬 6종

기본 구슬은 Lv1, Lv3, Lv5에서 동작이 변하고 Lv2, Lv4에서 주 수치가 성장한다. 아래 값은 행동 계약이며 정확한 확률과 피해량은 중앙 튜닝에서 조정한다.

### 5.1 관성 구슬

속도와 벽을 맞기 전 직격에 특화한다.

- Lv1: 이동 속도가 빠를수록 직접 피해 증가
- Lv2: 기본 속도와 속도 피해 상한 증가
- Lv3: 정밀 직격 시 대상 뒤로 충격파 발생
- Lv4: 정밀 직격 뒤 일정 시간 최고 속도 유지
- Lv5: 정밀 직격 시 적 하나를 관통하고 두 대상에 운동에너지 폭발

### 5.2 전도 구슬

밀집된 적 사이의 에너지 전달에 특화한다.

- Lv1: 충돌 시 가까운 적에게 연쇄 공격
- Lv2: 전달 거리와 대상 수 증가
- Lv3: 비행 중 가까운 적 하나를 약한 에너지선으로 지속 공격
- Lv4: 비행 공격의 대상 수와 틱 속도 증가
- Lv5: 직접 충돌 시 연결 중인 모든 적에게 과충전 피해

### 5.3 분열 구슬

확률적으로 임시 구슬을 만들어 다중 타격한다.

- Lv1: 적 충돌 시 일정 확률로 임시 구슬 2개 생성
- Lv2: 분열 확률 증가
- Lv3: 임시 구슬이 벽 또는 적에게 한 번 더 튕김
- Lv4: 임시 구슬 수와 유지 시간 증가
- Lv5: 임시 구슬이 허용된 공용 공격 효과 일부를 낮은 효율로 계승

임시 구슬은 재분열하지 않는다. 허용 효과와 계승 배율은 명시적 목록으로 제한한다.

### 5.4 부식 구슬

잔류 지역과 구조 약화에 특화한다.

- Lv1: 충돌 시 일정 확률로 부식 지역 생성
- Lv2: 지역 범위와 지속 시간 증가
- Lv3: 정밀 직격한 적에게 이동식 부식 지역 부착
- Lv4: 부식 중첩으로 적 방어력 감소
- Lv5: 부식된 적이 죽으면 주변에 작은 부식 지역 확산

### 5.5 반향 구슬

벽 반사로 힘을 저장해 다음 공격에서 방출한다.

- Lv1: 벽 충돌마다 공명 축적, 다음 적 충돌 피해 증가
- Lv2: 공명 상한과 중첩당 피해 증가
- Lv3: 공명 방출 시 작은 충격파 발생
- Lv4: 벽 충돌 시 낮은 확률로 수평 또는 수직 절단선 발생
- Lv5: 최대 공명 방출 시 직전 반사 경로를 따라 공명파 재생

### 5.6 폭발 구슬

확률과 실패 누적을 이용한 순간 범위 피해에 특화한다.

- Lv1: 적 충돌 시 일정 확률로 폭발
- Lv2: 폭발 피해 증가
- Lv3: 연속 실패할 때마다 다음 폭발 확률 증가
- Lv4: 폭발 범위 증가
- Lv5: 최대 실패 누적 뒤 중심부 고위력 폭발

분열 구슬과 합성하기 전에는 임시 구슬이 폭발 효과를 상속하지 않는다.

## 6. 융합 규칙

### 6.1 생성

- 등록된 레시피의 기본 구슬 두 개를 각각 하나씩 소비한다.
- 플레이어가 실제로 소비할 구슬 인스턴스를 선택한다.
- 결과 합성 구슬 하나를 만들고 슬롯 하나를 비운다.
- `융합 레벨 = 재료 A 레벨 + 재료 B 레벨 - 1`
- 합성 구슬 레벨은 최대 Lv9로 제한한다.
- 재료로 쓴 기본 구슬은 이후 핵 보급에서 다시 획득할 수 있다.

예:

```text
전도 Lv4 + 관성 Lv1
→ 광자 궤도 Lv4
```

### 6.2 이후 강화

- 합성 순간 레벨을 확정한다.
- 이후 재료 종류의 레벨 변화가 기존 합성 구슬에 전파되지 않는다.
- 합성 구슬은 전용 강화 선택으로 한 레벨씩 성장한다.
- Lv1에서 기본 융합 동작을 얻고 Lv4, Lv7, Lv9에서 동작 또는 연출이 진화한다.
- 그 사이 레벨은 피해, 확률, 대상 수, 지속 시간 중 한 축만 강화한다.
- 같은 합성 구슬은 한 런에 하나만 보유할 수 있다.
- 이미 보유한 합성 레시피는 다시 합성 선택지에 나오지 않는다.
- 합성 구슬은 다른 합성의 재료로 사용할 수 없다.

## 7. 1차 융합 구슬 9종

가능한 15개 조합을 전부 만들지 않는다. 각 기본 구슬이 세 레시피에 참여하도록 재미와 역할이 분명한 9개만 사용한다.

### 7.1 광자 궤도 — 관성 + 전도

- 속도로 광자 에너지를 축적한다.
- 정밀 직격 시 진행 방향으로 관통 레이저를 발사한다.
- 벽 반사 전 이동 경로에 짧은 잔광 레이저를 남긴다.
- 잔광이 교차하면 교차점에서 추가 폭발이 발생한다.

### 7.2 공명 군체 — 전도 + 분열

- 충돌 시 확률적으로 작은 공명체 여러 개를 분화한다.
- 공명체와 적 사이로 에너지가 왕복한다.
- 공명체가 가까이 모일수록 공격 주기가 빨라진다.
- 수명이 끝나면 본체 방향으로 모이며 마지막 공명파를 낸다.

### 7.3 나노 증식체 — 분열 + 부식

- 충돌 시 주변 위치에 나노머신 씨앗을 산개한다.
- 씨앗은 고정 지역에 지속 피해를 준다.
- 감염된 적이 죽으면 가까운 유효 지역으로 하나가 복제된다.
- 동시 씨앗 수와 세대 깊이는 제한한다.

### 7.4 질량 붕괴탄 — 부식 + 관성

- 고속 충돌로 적 내부에 구조 열화를 중첩한다.
- 임계 중첩에서 대상이 안쪽으로 붕괴한다.
- 붕괴 충격은 인접 적과 보스 파츠 하나에 감쇠 전달된다.
- 정밀 직격일수록 중첩량과 붕괴 피해가 증가한다.

### 7.5 반응로 구슬 — 반향 + 폭발

- 벽 충돌마다 반응로 충전을 얻는다.
- 다음 적 충돌 폭발이 충전 수에 따라 커진다.
- 최대 충전 폭발은 중심과 외곽의 두 단계 충격파를 만든다.
- 충전을 오래 보존할수록 구슬의 발광과 진동이 강해진다.

### 7.6 성단 폭격체 — 폭발 + 분열

- 적 충돌 시 확률적으로 폭발탄 6개가 포물선으로 산개한다.
- 탄은 대략 11시, 1시, 3시, 5시, 7시, 9시 방향으로 퍼진다.
- 각 탄은 유효 지점에 착탄해 작은 폭발을 만든다.
- 높은 레벨에서는 착탄 지점에 짧은 후속 충격 지대를 남긴다.

### 7.7 거울 회로 — 반향 + 전도

- 벽 충돌 지점에 짧게 유지되는 에너지 거울을 설치한다.
- 최근 거울끼리 광선을 연결한다.
- 연결선을 통과하거나 닿은 적에게 주기적으로 피해를 준다.
- 거울 수는 제한하고 새 거울이 생기면 가장 오래된 것을 교체한다.

### 7.8 융해 코어 — 폭발 + 부식

- 폭발 지점에 과열 지역을 남긴다.
- 같은 지역의 반복 폭발이 온도와 지속 피해를 높인다.
- 임계 온도에 도달하면 융해 폭발을 일으키고 지역을 소모한다.
- 보스 파츠에는 중첩 상한과 별도 감쇠율을 적용한다.

### 7.9 벡터 블레이드 — 관성 + 반향

- 벽 반사마다 다음 공격의 절단 벡터를 저장한다.
- 적 충돌 시 들어온 궤적 방향으로 절단파를 발사한다.
- 빠르고 긴 반사 경로일수록 절단파가 길고 강해진다.
- 최대 레벨에서는 마지막 두 반사 벡터를 연속 재생한다.

## 8. 핵 보급과 성장 간격

일반 경험치 레벨업과 핵 보급을 분리한다.

- 일반 레벨업: 공용 능력 3개 중 하나
- 핵 보급: 기본 구슬 추가, 개별 구슬 강화 또는 융합
- 보스 보상: 희귀 유물 3개 중 하나

### 8.1 슬롯이 남은 경우

- 핵 보급은 기본 구슬 추가 선택지만 제공한다.
- 어떤 종류를 선택해도 물리적 구슬 하나가 Lv1로 추가된다.
- 이미 가진 종류를 다시 선택할 수 있다.
- 기본 구슬 6개가 되기 전에는 개별 강화와 융합을 강요하지 않는다.

### 8.2 슬롯이 가득 찬 경우

- 유효한 융합과 보유 구슬 개별 강화에서 선택지를 만든다.
- 융합 선택 뒤 소비할 재료 두 개를 직접 선택한다.
- 융합으로 슬롯이 비면 다음 핵 보급은 다시 기본 구슬 추가를 제공한다.
- 유효한 융합이 없으면 개별 강화만 제공한다.
- 모든 가능한 대상이 최대 레벨이면 일반 능력 보상으로 대체한다.

### 8.3 스테이지별 시점

핵 보급은 실제 시간이나 현재 플레이어 화력이 아니라 스테이지 진행도를 따른다.

#### 1스테이지

- 시작: 구슬 1개
- 진행도 20%: 두 번째 구슬
- 진행도 55%: 세 번째 구슬
- 진행도 100%: 첫 보스

첫 보스는 구슬 3개 기준으로 조정하며 평균 빌드의 목표 전투 시간은 45~60초다.

#### 2스테이지

- 진행도 20%, 45%, 75%: 핵 보급
- 융합하지 않았다면 최대 6개에 도달
- 슬롯이 찼다면 첫 융합 또는 개별 강화가 가능
- 진행도 100%: 두 번째 보스

#### 이후

- 스테이지당 핵 보급 2~3회
- 정확한 시점은 스테이지 데이터에 둔다.
- 핵 보급과 일반 레벨업이 동시에 대기하면 핵 보급을 먼저 표시한다.
- 연속 보상 화면 사이에는 짧은 gameplay 재개 시간을 보장한다.

## 9. 발견과 영구 해금

### 9.1 기본 구슬

- 처음에는 반향 구슬만 시작 구슬로 해금한다.
- 잠긴 기본 구슬도 런 중 핵 보급에는 모두 출현할 수 있다.
- 미발견 구슬은 이름과 상세 효과를 `???`로 표시한다.
- 색상, 실루엣과 `직격형`, `분열형` 같은 짧은 역할 힌트는 표시한다.
- 처음 획득하면 해당 런에서 이름과 효과를 즉시 공개하고 도감에 발견 기록을 남긴다.
- 런 종료 뒤 작업장에서 무료 재화 해금 가격을 표시한다.
- 구매한 기본 구슬만 런 시작 구슬로 선택할 수 있다.

런 중 출현 여부와 시작 구슬 선택 권한을 분리한다. 해금하지 않아도 모든 기본 구슬과 빌드를 체험할 수 있다.

### 9.2 융합 구슬

- 유효한 재료를 보유하면 미발견 융합도 선택지에 등장할 수 있다.
- 미발견 융합은 결과 실루엣, 재료와 역할 힌트만 표시한다.
- 최초 합성 시 이름, 효과와 레시피를 도감에 등록한다.
- 발견한 융합은 이후 상세 결과를 미리 확인할 수 있다.
- 융합 레시피에는 별도 재화 해금을 요구하지 않는다.

## 10. 보상 선택 UI

보상 카드는 빠르게 훑을 수 있어야 한다.

### 10.1 기본 상태

- 카드에는 아이콘, 이름과 현재·다음 레벨만 표시한다.
- 처음에는 아무 카드도 선택하지 않는다.
- 선택되지 않은 상태에서는 상세 설명 패널을 숨긴다.
- 카드를 누르면 강조하고 화면 아래 상세 패널을 연다.
- 상세 패널의 `획득` 버튼으로 최종 확정한다.

### 10.2 설명 문구

- `px`, 내부 탐색 거리와 엔진 계수는 표시하지 않는다.
- 피해 증가율, 발동 확률과 지속 시간처럼 판단에 필요한 값은 표시할 수 있다.
- 공간 수치는 `범위 증가`, `더 먼 적에게 전달` 같은 플레이어 언어로 바꾼다.
- 긴 규칙 전문 대신 이번 선택으로 무엇이 달라지는지 우선 표시한다.

예:

```text
폭발 반경 48px → 56px
```

대신:

```text
폭발 범위 15% 증가
```

### 10.3 구슬 대상 선택

- 상세 패널 위에 활성 구슬 최대 6개의 작은 아이콘과 레벨을 표시한다.
- 개별 강화 선택 시 해당 종류 또는 가능한 대상만 강조한다.
- 대상이 하나면 자동 선택한다.
- 대상이 여러 개면 플레이어가 하나를 누른다.
- 융합은 가능한 재료만 강조하고 선택한 두 재료와 결과 레벨을 표시한다.
- 최종 획득 전 소비될 구슬과 생성될 합성 구슬을 다시 확인할 수 있다.

## 11. 난도와 파워 곡선

- 현재 구슬 수와 실제 레벨을 읽어 적을 즉시 강화하지 않는다.
- 스테이지 진행도와 예정된 핵 보급 시점을 기준으로 이후 생성되는 적 밴드를 강화한다.
- 이미 화면에 있는 적의 HP는 바꾸지 않는다.
- 난도는 적 하강 속도보다 HP, 크기, 수, 장갑과 특수 적 비율로 올린다.
- 첫 보스 전에는 구슬 3개를 전제로 HP와 이동 범위를 다시 측정한다.
- 두 번째 보스 전에는 구슬 5~6개 또는 첫 융합 하나를 전제로 측정한다.
- 강한 빌드는 예정 곡선보다 앞서갈 수 있어야 하며 자동 보정으로 이점을 지우지 않는다.

## 12. 중앙 데이터

기존 설정과 정의 방식을 확장한다. 외부 JSON 로더와 범용 효과 언어는 만들지 않는다.

- 기본 구슬 ID, 최대 레벨과 레벨별 행동 값
- 합성 레시피, 결과 ID와 최대 레벨
- 구슬 슬롯 상한
- 스테이지별 핵 보급 진행도
- 발견 힌트와 공개 설명
- 융합별 임시 개체 상한, 피해 감쇠와 재귀 제한
- 적 파워 밴드와 보스 목표 시간

플레이어 설명과 실제 정의가 서로 다른 숫자를 갖지 않도록 같은 정의에서 UI 문구에 필요한 값을 읽는다.

## 13. 경계 조건

- 존재하지 않는 구슬과 레시피 ID는 시작 시 오류로 처리한다.
- 기본 구슬 레벨은 1~5, 합성 구슬 레벨은 1~9를 벗어날 수 없다.
- 슬롯 6개를 초과하는 추가 구슬 선택은 만들지 않는다.
- 재료 구슬이 보상 확정 전에 사라지면 융합을 취소하고 선택 화면을 다시 계산한다.
- 같은 구슬 인스턴스를 두 재료로 선택할 수 없다.
- 같은 합성 구슬을 중복 생성할 수 없다.
- 일시정지와 보상 화면에서는 구슬, 적과 예약 효과 시간이 진행되지 않는다.
- 임시 구슬, 나노 씨앗, 거울과 잔광은 각 효과의 동시 상한을 따른다.
- 보스 파츠 겹침으로 같은 보조 효과가 한 파츠를 중복 타격하지 않는다.

## 14. 검증

### 14.1 순수 규칙

- 같은 종류의 구슬이 서로 다른 레벨을 유지
- 선택한 구슬 하나만 강화
- 새 구슬이 항상 Lv1로 추가
- 두 재료 소비와 `A + B - 1` 융합 레벨
- 융합 뒤 슬롯 하나 해방
- 중복 융합과 합성 구슬 재료 사용 차단
- 슬롯 상태에 따른 추가·강화·융합 선택지
- 미발견·발견·시작 해금 상태 전환
- 진행도별 핵 보급 순서와 중복 방지

### 14.2 브라우저 자동 검증

- 구슬 하나로 시작
- 첫 보스 전에 두 번의 핵 보급과 구슬 3개 도달
- 구슬 6개에서 개별 강화와 유효 융합 표시
- 중복 구슬 중 하나만 선택해 강화
- 융합 재료 선택, 결과 레벨과 슬롯 해방
- `???` 구슬 최초 획득 뒤 정보 공개
- 카드 선택 전 상세 패널 숨김
- 카드 선택 뒤 상세 패널과 획득 버튼 표시
- 데스크톱과 모바일에서 구슬 6개 대상 행 조작

### 14.3 직접 플레이 검증

- 첫 보스 전 구슬 증가가 지나치게 늦거나 잦지 않음
- 구슬 3개로 첫 보스가 45~60초 안에 끝남
- 개별 강화 대상 선택이 번거로움보다 전략으로 느껴짐
- 강한 재료와 약한 재료 중 무엇을 융합할지 고민이 생김
- 합성 전후 공격 방식과 화면 연출이 분명히 달라짐
- 미발견 구슬의 힌트가 선택에 충분하지만 발견 재미를 해치지 않음
- 보상 설명을 한 번에 읽을 수 있고 내부 구현 단위가 노출되지 않음

## 15. 구현 범위 분할

구현은 다음 묶음으로 나눈다.

1. 개별 구슬 레벨, 구슬 1개 시작과 진행도 기반 핵 보급
2. 간결한 보상 카드, 상세 패널과 구슬 대상 선택
3. 기본 구슬 6종의 Lv1~5
4. 융합 규칙과 첫 3종 수직 구현
5. 나머지 융합 6종을 3종씩 구현
6. 발견, 도감과 시작 구슬 해금 연결
7. 첫·두 번째 보스와 적 파워 밴드 재측정

각 묶음에서 관련 단위 검증을 먼저 만들고, 실제 브라우저 검증은 UI 또는 전투 통합이 바뀐 묶음 끝에 한 번 수행한다. 매 작은 내부 변경마다 전체 브라우저 테스트를 반복하지 않는다.

## 16. 제외

- 3구슬 초월 합성
- 합성 구슬끼리의 합성
- 가능한 모든 기본 구슬 조합
- 개별 구슬 장비창과 런 중 드래그 정렬
- 구슬별 영구 경험치와 사용 숙련도
- 실제 미술과 사운드 리소스 제작
- 실시간 플레이어 화력 기반 적 자동 보정

이 항목은 기본 6종과 융합 9종의 실제 플레이가 검증된 뒤 별도로 판단한다.
