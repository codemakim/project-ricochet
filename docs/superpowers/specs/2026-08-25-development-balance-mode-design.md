# 개발자 밸런스 테스트 모드 설계

## 목적

개발 빌드에서 전투 밸런스 수치를 바꾼 뒤 즉시 같은 조건으로 플레이한다.
일반 플레이 설정, 해금, 부품, 기록에는 영향을 주지 않는다. 같은 시드를 유지해
수치 하나만 바꾼 A/B 플레이가 가능해야 한다.

## 진입과 반복 흐름

개발 빌드의 출격 준비 화면에만 `밸런스 테스트` 버튼을 표시한다. 버튼을 누르면
설정 패널이 열린다. `테스트 시작`은 현재 시작 코어와 테스트 설정으로 전투를 바로
시작한다.

테스트 종료 화면은 다음 세 동작을 제공한다.

- 같은 설정 재시작
- 수치 수정
- 일반 출격 화면으로 복귀

테스트 런 결과는 `MetaStore`, 부품 정산, 발견·해금 기록에 반영하지 않는다.

## 조정 항목

| 항목 | 의미 | 초기값 | 허용 범위 |
| --- | --- | --- | --- |
| 일반 적 HP | 기본·슈터·분열·분열 잔체 체력 배율 | 1.0 | 0.1~10.0 |
| 특수 적 HP | 장갑 적과 이후 대형·특수 적 체력 배율 | 1.0 | 0.1~10.0 |
| 적 하강 속도 | 모든 일반 적의 세로 이동 속도 배율 | 1.0 | 0.0~5.0 |
| 적 수 | 단계별 동시 인구 상한 배율 | 1.0 | 0.25~4.0 |
| 증원 간격 | 단계별 증원 대기시간 배율. 작을수록 자주 등장 | 1.0 | 0.1~4.0 |
| 플레이어 피해 | 모든 플레이어 소유 피해 배율 | 1.0 | 0.1~10.0 |
| 구슬 속도 | 회수 후 발사되는 모든 영구 구슬의 속도 배율 | 1.0 | 0.25~4.0 |
| 시작 구슬 수 | 선택한 시작 코어로 생성할 구슬 수 | 1 | 1~6 |
| 시드 | 적 구성과 보상 난수 재현값 | 현재 생성값 | 0~4294967295 정수 |

입력 옆에는 기본 배율과 대표 원본 수치를 표시한다. 예를 들어 적 HP는
`기본 3 / 슈터 4 / 장갑 10`, 하강 속도는 `8px/s`를 함께 보여준다. 단계와 적
종류에 따라 원본 수치가 달라지는 항목은 절대값으로 위장하지 않고 배율로 표시한다.

## 저장과 초기화

마지막 테스트 설정은 개발자 전용 `localStorage` 키 하나에 저장한다. 새로고침과
테스트 종료 뒤에도 유지한다. `기본값 복원`은 모든 배율을 1.0, 시작 구슬을 1로
돌리고 새 시드를 만든다. 저장 데이터가 없거나 유효하지 않으면 기본값을 사용한다.

## 런타임 구조

`RunConfig`에 선택적 개발자 설정을 추가한다. 일반 출격은 이 필드를 전달하지
않는다. `AppController`는 개발 빌드에서만 설정 UI를 만들고 테스트 런을 시작한다.

런 설정은 다음 경계에서 한 번씩 적용한다.

- `EncounterDirector`: 동시 인구 상한과 증원 간격
- `EnemyManager`: 적 종류별 HP와 하강 속도
- 플레이어 피해 경계: 직접 타격, 지속 피해, 범위 피해, 임시 구슬, 융합 효과
- 보스 피해 경계: 같은 플레이어 피해 배율
- `OrbManager`: 시작 구슬 수

`GAME_TUNING`은 수정하거나 복제하지 않는다. 개발자 설정은 현재 런 인스턴스에만
존재한다. 테스트 런이 끝나면 게임 인스턴스와 함께 폐기한다.

## 피해 배율 규칙

플레이어 피해 배율은 피해 출처가 아니라 소유권을 기준으로 적용한다. 구슬 직접
타격, 폭발, 전도, 부식 지속 피해, 분열·임시 구슬, 보조무기, 융합 효과와 보스
피해에 정확히 한 번 적용한다. 적 탄환, 적 접촉, 최하단 침입 피해에는 적용하지
않는다. 피해 이벤트가 다른 효과를 다시 만들더라도 중복 배율을 금지한다.

## 검증과 오류 처리

- 숫자 입력은 유한값과 범위를 확인하고 잘못된 항목 옆에 오류를 표시한다.
- 오류가 하나라도 있으면 테스트 시작을 비활성화한다.
- 저장 데이터는 로드 시 다시 검증한다.
- 프로덕션 빌드에는 진입 버튼과 전역 개발 훅이 나타나지 않는다.
- 일반 런 결과만 메타 진행을 정산한다.

## 테스트

- 설정 파서의 기본값, 범위, 손상된 저장값 복구
- 테스트 런과 일반 런의 `RunConfig` 격리
- 일반/특수 적 HP, 하강 속도, 동시 인구와 증원 간격 적용
- 직접·지속·범위·임시·융합·보스 피해에 배율이 정확히 한 번 적용
- 시작 구슬 수 1과 6
- 테스트 종료 뒤 메타 진행 불변과 같은 설정 재시작
- 데스크톱·모바일 설정 패널, 입력 오류, 시작·수정·재시작 브라우저 흐름

## 제외 범위

런 도중 실시간 수치 변경, 보스별 세부 패턴 편집, 능력 강제 부여, 스테이지 점프,
설정 파일 내보내기는 이번 작업에 포함하지 않는다. 첫 밸런스 반복에서 실제 필요가
확인되면 같은 개발자 모드에 추가한다.
