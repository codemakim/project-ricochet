# Project Ricochet 런 빌드 시스템 리디자인

## 1. 목적

이 문서는 Project Ricochet의 영구 구슬, 일반 레벨업, 보스 희귀 보상, 확률형 전투 효과를 하나의 빌드 시스템으로 재설계한다.

현재 프로토타입은 성장 체감은 강하지만 다음 문제가 있다.

- 폭발이 등급마다 피해와 범위를 함께 올려 지나치게 빠르게 성장한다.
- 분열이 확정 발동하고 임시 구슬도 폭발을 일으켜 화면 화력과 보스 파츠 피해가 폭증한다.
- 두 번째 보스 도달 전에 일반 적과 보스 파츠가 순식간에 파괴된다.
- 선택지가 적어 매 런의 성장 경로가 비슷하다.
- 구슬의 이동, 직접 회수, 조준, 벽 반사 같은 고유 조작이 빌드 선택과 충분히 연결되지 않는다.
- 두 번째 보스의 일부 파츠 충돌과 영구 노출 이후 움직임이 의도와 다르다.

새 시스템의 목표는 숫자 하나를 반복 강화하는 방식이 아니라 작은 효과들을 조합해 강해지는 로그라이트 빌드를 만드는 것이다. 플레이어는 위치, 조준, 회수 타이밍으로 빌드 성능을 능동적으로 끌어낼 수 있어야 한다.

## 2. 범위

### 2.1 포함

- 영구 구슬 4종과 런 시작 구성 선택
- 일반 레벨업 선택지 33종
- 한 런의 일반 능력 종류 상한 12개
- 능력별 독립 최대 등급
- 직접 타격, 속도, 벽 반사, 근접 회수 중심 시너지
- 폭발, 분열, 레이저, 부식 가스, 미사일 같은 확률·카운터형 효과
- 임시 구슬의 발동 제한과 재귀 방지
- 보스 희귀 보상
- 결정적 난수와 확률 실패 보호
- 성장 수치의 중앙 설정
- 두 번째 보스 파츠 충돌과 영구 노출 이동 수정
- 새 성장 곡선에 맞춘 경험치 및 보스 체력 재조정 절차

### 2.2 제외

- 영구 메타 성장과 계정 저장
- 구슬 해금 재화
- 정식 세계관, 캐릭터 이름, 미술 리소스, 사운드
- 외부 JSON 로딩과 모딩
- 새 일반 적과 새 보스 구현
- 임시 구슬이 일반 효과를 무제한 상속하는 구조
- 모든 효과를 표현하는 범용 스크립트 언어

## 3. 제품 원칙

### 3.1 조작이 빌드 성능을 결정한다

Project Ricochet의 차별점은 자유 이동과 능동 회수다. 다음 조건은 플레이어가 의도적으로 만들 수 있으므로 확률이 아니라 확정 판정으로 동작한다.

- 적 가까이에서 직접 타격
- 발사 후 벽에 닿기 전 직접 타격
- 직접 회수 후 첫 직접 타격
- 벽 반사 횟수
- 벽 없이 연속 직접 타격
- 직접 처치
- 높은 속도로 직접 타격

폭발, 분열, 레이저처럼 화면 결과가 큰 효과는 확률 또는 적중 카운터로 발동한다. 조작 성공 여부와 큰 효과의 발동 여부를 분리해 플레이어 통제와 로그라이트 변동성을 함께 유지한다.

### 3.2 작은 옵션을 조합한다

하나의 선택이 피해, 범위, 발동률을 동시에 올리지 않는다.

- 효과 해금
- 효과 피해
- 효과 범위
- 발동 확률
- 지속 시간
- 생성 수
- 투사체 피해

각 항목은 별도 능력이다. 따라서 폭발 하나만 반복 선택해 완성하는 대신 여러 작은 능력을 조합해야 한다.

### 3.3 영구 구슬만 발동 주체다

- 영구 구슬의 직접 타격만 폭발, 분열, 레이저, 미사일 같은 발동 효과를 시작한다.
- 임시 구슬, 폭발, 레이저, 가스, 미사일, 연쇄 번개는 기본적으로 다른 발동 효과를 시작하지 않는다.
- 같은 영구 구슬 직접 타격에서 서로 다른 효과가 각각 발동할 수 있다.
- 동일 효과는 한 직접 타격에서 한 번만 발동한다.
- 보스 희귀 보상만 제한적인 임시 구슬 상속이나 2차 분열을 허용한다.

이 규칙으로 재귀 폭증을 막으면서 한 번의 적중에서 여러 효과가 겹치는 도파민은 유지한다.

### 3.4 참고작은 문법만 참고한다

Bounce Defense와 BALL x PIT에서 다음 장르 문법을 참고한다.

- 수평·수직 레이저
- 분열 구슬
- 처치 폭발
- 벽 반사 및 복귀와 연계되는 성장
- 촘촘한 적 대형을 연쇄 효과로 정리하는 전투

고유 캐릭터, UI 배치, 아이콘, 명칭, 수치, 애니메이션, 사운드는 복제하지 않는다. Project Ricochet은 기계 테마, 자유로운 2D 이동, 근접 회수와 즉시 재발사로 구분한다.

## 4. 핵심 전투 용어

- `영구 구슬`: 회수되고 재발사되는 플레이어의 주무기. 런 시작 시 3개, 최대 6개다.
- `임시 구슬`: 분열로 생겨 짧게 활동한 뒤 소멸하는 보조 투사체다.
- `직접 타격`: 영구 구슬 또는 임시 구슬 몸체가 적 몸체와 충돌해 주 대상 피해를 주는 사건이다.
- `영구 직접 타격`: 영구 구슬의 직접 타격이다. 일반 발동 효과의 유일한 시작점이다.
- `첫 직접 타격`: 영구 구슬이 발사된 뒤 처음 발생한 영구 직접 타격이다.
- `정밀 직접 타격`: 발사 후 벽 충돌이 한 번도 없었던 상태의 영구 직접 타격이다.
- `근접 회수`: 플레이어가 흡수 반경 안에 들어가 시작한 `proximity` 회수다.
- `강제 귀환`: 바닥 충돌 또는 선택적 시간 제한으로 시작한 `floorRecall`, `timeoutRecall`이다.
- `보조 피해`: 직접 타격 외의 폭발, 레이저, 가스, 미사일, 연쇄 번개 피해다.
- `발동 효과`: 영구 직접 타격을 입력으로 새 공격을 생성하는 효과다.

## 5. 영구 구슬 구성

### 5.1 런 시작

- 런 시작 시 영구 구슬 3개를 가진다.
- 간단한 시작 구성 화면에서 각 슬롯의 구슬 종류를 선택한다.
- 같은 종류를 여러 슬롯에 선택할 수 있다.
- 각 구슬은 자신의 종류와 상태를 독립적으로 보존한다.
- 추가 영구 구슬 능력을 처음 선택할 때 새 구슬의 종류도 고른다.
- 전투 중 선택 화면이 열리면 기존 레벨업처럼 전투를 완전히 정지한다.
- 최대 6개에서 추가 영구 구슬 선택지는 나오지 않는다.
- 구슬 종류는 일반 능력 12종 상한에 포함하지 않는다.

### 5.2 공통 생명주기

기존 생명주기를 유지한다.

`stored -> queued -> active -> attracting 또는 floor-returning -> stored`

- 근접 회수와 바닥 귀환 모두 구슬을 다시 발사 가능하게 한다.
- 흡수된 구슬은 현재 고정된 조준 방향으로 자동 재발사된다.
- 기존 기본 충전은 유지한다. 재발사 시 직접 타격 3회가 `1.5배` 피해를 주며 직접 타격마다 1회 소모한다.
- 구슬 종류의 고유 능력과 일반 능력은 기본 충전과 별도 계층으로 계산한다.
- 강제 귀환은 근접 회수 전용 효과를 발동하지 않는다.

### 5.3 반향 코어

벽 반사로 공명하고 다음 직접 타격에서 공명을 방출한다.

- 벽 충돌마다 공명 1중첩
- 기본 최대 5중첩
- 중첩당 다음 영구 직접 타격 피해 `+8%`
- 영구 직접 타격 후 모든 공명 소모
- 회수와 강제 귀환은 남은 공명을 제거
- 적 타격은 공명 중첩을 만들지 않음

직선 조준보다 반사각을 설계하는 플레이에 적합하다.

### 5.4 부식 코어

직접 타격으로 고정된 부식 가스 지역을 만든다.

- 영구 직접 타격마다 기본 `15%` 확률
- 반경 `42px`
- 지속 `2.5초`
- `0.5초`마다 기본 직접 피해의 `20%`
- 같은 코어가 만든 가스는 최대 2개
- 새 가스가 상한을 넘으면 가장 오래된 가스를 제거
- 가스 피해는 다른 효과를 발동하지 않음

기계 테마에서는 독 대신 냉각제 누출, 부식성 가스, 나노머신 안개로 표현한다.

### 5.5 전도 코어

직접 타격 횟수를 축적해 연쇄 전류를 방출한다.

- 영구 직접 타격 4회마다 발동
- 주 대상 외 가까운 적 최대 2개
- 대상당 기본 직접 피해의 `45%`
- 같은 적을 한 번의 연쇄에서 중복 선택하지 않음
- 발동 후 카운터 0으로 초기화
- 회수와 강제 귀환은 카운터를 보존
- 연쇄 피해는 다른 효과를 발동하지 않음

고밀도 적 대형에서 안정적인 정리 능력을 제공한다.

### 5.6 관성 코어

직접 타격으로 관성을 축적하고 능동 회수로 다음 발사 속도를 높인다.

- 영구 직접 타격마다 관성 1중첩
- 기본 최대 3중첩
- 근접 회수 시 중첩당 다음 발사 속도 `+10%`
- 속도 보너스는 다음 첫 영구 직접 타격 직후 종료
- 바닥 귀환과 시간제 귀환은 관성 중첩을 모두 잃음
- 벽 충돌은 관성을 만들지 않음
- 근접 회수하지 않은 상태에서 다시 발사되는 예외 경로가 생겨도 관성 보너스를 받지 않음

관성 코어는 적을 여러 번 직접 맞힌 뒤 위험을 감수하고 직접 회수할수록 강해진다. 별도의 회수 코어는 만들지 않는다.

## 6. 일반 레벨업 구조

### 6.1 획득 규칙

- 레벨업마다 중복 없는 3개 선택지를 표시한다.
- 한 런에서 일반 능력은 최대 12종까지 획득할 수 있다.
- 이미 가진 능력의 등급 상승은 12종 상한을 소비하지 않는다.
- 12종을 채운 뒤에는 가진 능력 중 최대 등급이 아닌 능력만 표시한다.
- 가능한 능력이 3개보다 적으면 가능한 수만 표시한다.
- 모든 가진 능력이 최대 등급이면 경험치 획득을 중단하고 레벨업 화면을 열지 않는다.
- 구슬 종류와 보스 희귀 보상은 12종 상한에 포함하지 않는다.
- 선택지 생성은 런 seed를 사용해 재현 가능해야 한다.

### 6.2 관련성 조건

효과를 사용할 수 없는 선택지는 표시하지 않는다.

- 효과 피해, 범위, 지속 시간, 발동률 강화는 해당 효과를 먼저 해금해야 등장한다.
- 빔 두께는 수평 또는 수직 레이저가 있어야 등장한다.
- 파편 수, 피해, 수명은 분열 프로토콜이 있어야 등장한다.
- 전도 대상 수는 전도 코어를 하나 이상 보유해야 등장한다.
- 구슬 종류 전용 능력은 해당 종류를 하나 이상 보유해야 등장한다.

관련성 조건은 빌드를 강제하는 전용 트리가 아니다. 조건을 만족하면 모든 적합한 일반 선택과 함께 같은 풀에 들어간다.

### 6.3 등급 정책

- 해금형 대형 효과는 대부분 최대 1등급
- 플레이 감각을 바꾸는 유틸리티는 최대 2~3등급
- 순수 수치 성장은 최대 3~5등급
- 최대 등급과 등급별 값은 중앙 설정에서 능력별로 정의
- 한 등급에서 둘 이상의 성장 축을 동시에 올리지 않음

## 7. 일반 능력 풀

초기 풀은 33종이다. 명칭은 기계 테마 임시 명칭이며 정식 아트 단계에서 바꿀 수 있다.

### 7.1 기본 능력

| 능력 | 최대 등급 | 등급 효과 |
|---|---:|---|
| 화력 증폭 | 5 | 영구·임시 직접 피해 `+12%` |
| 운동 에너지 | 3 | 모든 영구 구슬 기본 속도 `+7%` |
| 추가 코어 | 3 | 영구 구슬 1개 추가, 최대 6개 |
| 코어 팽창 | 2 | 구슬 반경 `+8%` |
| 흡수장 확장 | 3 | 근접 회수 반경 `+8px` |
| 기동 모터 | 2 | 플레이어 이동 속도 `+8%` |
| 장갑 보강 | 3 | 최대 체력 `+1`, 즉시 1 회복 |

구슬 크기는 적 충돌 가능성을 높이지만 벽 통로와 보스 geometry를 깨지 않도록 최종 반경 상한을 둔다.

### 7.2 직접 타격과 위치 능력

| 능력 | 최대 등급 | 등급 효과 |
|---|---:|---|
| 근접 증폭 | 3 | 플레이어와 주 대상 거리가 `150px` 이하면 영구 직접 피해 `+15%` |
| 정밀 직격 | 3 | 정밀 직접 타격 피해 `+20%` |
| 재장전 과충전 | 3 | 근접 회수 뒤 첫 영구 직접 타격 피해 `+20%` |
| 연속 충돌 | 3 | 벽 없이 이어진 영구 직접 타격마다 `+10%`, 최대 3중첩 |
| 처치 오버클럭 | 3 | 영구 직접 처치한 구슬이 `2초` 동안 속도와 직접 피해 `+8%` |
| 충돌 가속 | 2 | 영구 직접 타격 뒤 `0.8초` 동안 해당 구슬 속도 `+8%` |
| 운동 변환 | 3 | 기준 속도 초과분 `10%`마다 영구 직접 피해 `+6%`, 최대 `+36%` |
| 추적 자석 | 2 | 첫 영구 직접 타격 뒤 `1.2초` 동안 해당 구슬의 흡수 반경 `+16px` |
| 벽 가속 | 3 | 발사 후 벽 충돌마다 속도 `+4%`, 최대 5중첩, 회수 시 초기화 |
| 고속 충격 | 1 | 기준 속도 `130%` 이상 영구 직접 타격 5회마다 작은 충격파 |

`근접 증폭`은 적과 충돌할 위험을 감수하고 가까이 이동할 이유를 만든다. `정밀 직격`, `재장전 과충전`, `추적 자석`, `충돌 가속`은 직접 맞히고 빨리 회수해 다시 쏘는 짧은 순환을 강화한다.

### 7.3 발동 효과

| 능력 | 최대 등급 | 기본 발동 |
|---|---:|---|
| 충격 폭발 | 1 | 영구 직접 타격 시 `20%`, 반경 `48px`, 직접 피해의 `45%` |
| 분열 프로토콜 | 1 | 영구 직접 타격 시 `25%`, 임시 구슬 2개 |
| 수평 절단선 | 1 | 영구 직접 타격 시 `15%`, 타격 위치에서 수평 레이저 |
| 수직 절단선 | 1 | 영구 직접 타격 시 `15%`, 타격 위치에서 수직 레이저 |
| 파괴 반응 | 1 | 영구 직접 처치 시 `25%`, 처치 위치 폭발 |
| 미세 유도탄 | 1 | 영구 직접 타격 6회마다 가까운 적에게 미사일 1발 |
| 회수 충격파 | 2 | 근접 회수 4회마다 플레이어 주변 피해, 등급당 피해 증가 |

모든 확률은 초기 튜닝 값이다. 각 효과의 확률, 피해, 범위, 카운터, 재발동 제한은 중앙 설정에 둔다.

### 7.4 효과 조정 능력

| 능력 | 최대 등급 | 등급 효과 |
|---|---:|---|
| 발동 최적화 | 2 | 보유한 확률형 발동 효과의 기본 확률에 `+4%p` |
| 효과 출력 | 3 | 보조 피해 `+15%` |
| 영향권 확장 | 3 | 원형 보조 효과 반경 `+10%` |
| 잔류 장치 | 2 | 가스와 시간제 효과 지속 시간 `+15%` |
| 집속 렌즈 | 2 | 수평·수직 레이저 두께 `+20%` |
| 파편 증설 | 2 | 분열 시 임시 구슬 `+1` |
| 파편 출력 | 3 | 임시 구슬 직접 피해 `+15%` |
| 파편 안정화 | 2 | 임시 구슬 수명 `+0.35초` |
| 전도 확장 | 2 | 전도 코어의 추가 대상 `+1` |

`효과 출력`은 폭발, 레이저, 가스, 미사일, 연쇄 번개, 충격파에만 적용한다. 임시 구슬 직접 피해는 `파편 출력`으로만 올린다.

## 8. 발동과 피해 처리

### 8.1 처리 순서

영구 직접 타격 하나는 다음 순서로 처리한다.

```text
충돌 전 구슬 상태 스냅샷
→ 직접 피해 배율 계산
→ 주 대상 직접 피해
→ 처치 여부 확정
→ 구슬 종류 고유 효과 갱신 또는 발동
→ 일반 발동 효과 판정
→ 충전, 공명, 관성, 연속 타격 상태 갱신
→ 반사 또는 관통 처리
→ 사망·경험치 이벤트 정산
```

직접 피해는 다음 세 묶음으로 계산한다.

```text
기본 구슬 피해
× (1 + 화력 증폭)
× 기본 충전 배율
× (1 + 구슬 종류 보너스 + 조건부 직접 피해 보너스)
```

- 조건부 직접 피해 보너스는 거리, 정밀 직격, 회수 과충전, 연속 충돌, 오버클럭, 운동 변환을 합산한다.
- 구슬 종류와 조건부 직접 피해 보너스의 합은 기본 `+150%`에서 제한한다.
- 보조 효과의 기준 피해는 `기본 구슬 피해 × (1 + 화력 증폭)`이다.
- 기본 충전, 구슬 종류와 조건부 직접 피해 보너스는 보조 효과에 적용하지 않는다.
- `효과 출력`과 해당 효과 전용 보스 보상만 보조 피해를 추가로 바꾼다.

이 분리로 직접 타격 빌드는 강한 직격을 만들 수 있지만 폭발과 분열까지 같은 배율로 폭증하지 않는다.

### 8.2 발동 제한

- 같은 영구 구슬과 같은 적은 기존 재타격 제한 안에서 한 번만 직접 타격 처리
- 확률형 효과별로 구슬당 `120ms` 재발동 제한
- 한 직접 타격에서 같은 효과 중복 발동 금지
- 서로 다른 효과의 동시 발동 허용
- 보조 피해는 직접 타격, 충전 소모, 반사, 관성, 공명, 발동 효과를 만들지 않음
- 임시 구슬 직접 타격은 직접 피해와 반사만 처리
- 임시 구슬은 바닥에 닿으면 소멸하며 회수되지 않음
- 동시 임시 구슬 기본 상한 30개

### 8.3 결정적 확률과 실패 보호

- 모든 확률 판정은 런 seed와 효과별 발동 순번을 사용한다.
- 같은 seed, 입력, 적중 순서에서는 같은 결과가 나와야 한다.
- 각 확률형 효과는 연속 실패 횟수를 독립적으로 가진다.
- 기본 확률을 `p`라 할 때 `ceil(2 / p)`번째 적격 판정은 이전까지 계속 실패했다면 강제 성공한다.
- 성공하면 해당 효과의 실패 횟수를 0으로 초기화한다.
- `발동 최적화`가 확률을 바꾸면 새 확률로 강제 성공 한계를 다시 계산한다.

예를 들어 기본 25% 효과는 최대 8번째 적격 판정에서 발동한다. 이 보호는 긴 무발동 구간만 막고 일반 판정의 확률은 올리지 않는다.

### 8.4 분열 규칙

- 기본 발동률 `25%`
- 기본 임시 구슬 2개
- 기본 수명 `1.5초`
- 기본 피해는 영구 구슬 기본 직접 피해의 `40%`
- 생성 방향은 충돌 후 예상 반사 방향을 중심으로 대칭 분산
- 하나의 영구 구슬은 한 번의 비행에서 분열을 한 번만 발동
- 근접 회수 또는 강제 귀환 뒤 재발사하면 새 비행으로 간주
- 임시 구슬은 폭발, 레이저, 가스, 미사일, 추가 분열을 발동하지 않음

분열은 초반 확정 화면 정리가 아니라 가끔 터지는 고점으로 바뀐다. `파편 증설`, `파편 출력`, `파편 안정화`를 함께 모아야 기존의 대규모 탄막에 가까워진다.

## 9. 보스 희귀 보상

보스를 처치하면 일반 레벨업보다 강하고 규칙을 바꾸는 보상 3개 중 1개를 선택한다. 같은 보스 희귀 보상은 한 런에서 중복되지 않는다.

| 보상 | 효과 |
|---|---|
| 보조체 연결 | 임시 구슬이 보유한 확률형 발동 효과를 기본 확률의 `25%`로 발동 가능 |
| 교차 절단 | 수평 또는 수직 레이저가 발동하면 다른 방향 레이저도 피해 `60%`로 발동 |
| 가스 점화 | 폭발이 부식 가스를 맞히면 남은 지속 피해의 `50%`를 즉시 주고 가스 제거 |
| 재귀 분열 | 임시 구슬이 수명 중 한 번, 기본 확률의 `20%`로 임시 구슬 1개 생성 |
| 관성 보존 | 관성 코어의 속도 보너스가 첫 직접 타격이 아니라 두 번째 직접 타격 뒤 종료 |
| 완전 순환 | 근접 회수 강화 첫 타격으로 처치하면 해당 영구 구슬이 즉시 무충돌 귀환 |
| 직격 연동 | 재장전 과충전 배율의 `30%`를 같은 타격에서 발동한 보조 피해에도 적용 |
| 초전도 회로 | 전도 코어 카운터 요구량 `-1`, 연쇄 대상당 피해 `+20%` |
| 공명 파열 | 반향 코어가 최대 공명으로 직접 타격하면 작은 확정 충격파 발생 |

예외 보상에도 안전장치를 둔다.

- `보조체 연결`로 발동한 효과는 다른 효과를 다시 발동하지 않는다.
- `재귀 분열`은 계보당 한 번이며 손자 임시 구슬은 다시 분열하지 않는다.
- 보스 보상으로 생긴 임시 구슬도 전체 임시 구슬 상한을 따른다.
- 해당 구슬 종류나 일반 효과가 없는 보상은 선택지에 나오지 않는다.

## 10. 경험치와 파워 곡선

### 10.1 목표

- 첫 레벨업은 현재보다 늦게 발생
- 첫 보스 전 일반 선택 수는 현재보다 줄지 않음
- 두 번째 보스 입장 시 일반 레벨업 선택 누적 `8~9회`
- 같은 능력 하나만으로 보스 파츠 전체가 순식간에 파괴되지 않음
- 성장 직후 일반 적이 바로 무력화되지 않도록 적 밀도와 체력으로 대응
- 적 하강 속도는 난도 상승의 주 수단으로 사용하지 않음

### 10.2 조정 순서

1. 새 능력 구조와 발동 제한을 먼저 적용한다.
2. 고정 seed 자동 전투로 보스별 도달 레벨과 선택 횟수를 기록한다.
3. 경험치 요구량을 조정해 두 번째 보스 입장 선택 수를 8~9회로 맞춘다.
4. 일반 적은 하강 속도를 유지하고 수, HP, 장갑형·특수형 비율 순서로 조정한다.
5. 보스 파츠와 코어 HP를 목표 전투 시간에 맞춘다.

플레이어 성장에 비례해 같은 순간 적 수치를 자동 보정하는 rubber-banding은 사용하지 않는다.

## 11. 두 번째 보스 수정

### 11.1 반사 파츠 충돌

현재 하단 총신처럼 보이는 반사 파츠가 피해만 받고 구슬을 통과시키는 동작은 오류다.

- 파츠가 살아 있는 동안 모든 전투 단계에서 영구·임시 구슬을 물리적으로 반사
- 같은 충돌에서 파츠 피해도 정상 적용
- 파괴된 즉시 collider와 hitbox 제거
- 폭발과 레이저 같은 보조 피해는 물리 반사를 만들지 않음

### 11.2 영구 노출 코어 이동

모든 파츠가 파괴되면 코어는 가만히 있지 않는다.

- 화면 상단 보스 전용 영역 안에서 좌우 연속 이동
- 파츠가 없으므로 기존 빈 공간 제한 없이 지정된 경계까지 이동
- 기존 파츠 보유 단계보다 느린 일정 속도
- 경계에 닿으면 방향 전환
- 확산탄과 조준탄은 매 발사 시점의 실제 코어 위치에서 생성
- 정지, 패배, 보상 전환 중 이동 정지

기존 분노 단계의 확산탄과 조준탄 조합은 유지한다. 발수, 간격, 탄속, 이동 속도는 중앙 설정으로 조정한다.

### 11.3 보스 피해 정책

- 직접 타격은 맞은 파츠에 정상 피해
- 폭발은 기존 설계대로 가장 가까운 보조 파츠 최대 1개에 감쇠 피해
- 레이저와 연쇄 번개도 한 발동에서 같은 보스의 여러 파츠를 무제한 타격하지 않음
- 보스별 보조 피해 대상 상한과 감쇠율을 중앙 설정에 둠
- 새 빌드 구현 뒤 고정된 옛 HP 수치를 먼저 올리지 않고 실제 전투 시간을 측정해 조정

## 12. 구조

기존 모듈을 확장하고 범용 능력 프레임워크를 새로 만들지 않는다.

### 12.1 `BuildState`

- 일반 능력 ID와 등급 소유
- 12종 상한과 최대 등급 검증
- 현재 능력으로부터 직접 피해 및 보조 효과 수치 계산
- 선택지 관련성 조건 제공
- Phaser 객체를 알지 않음

### 12.2 `ProgressionManager`

- 경험치, 레벨, 대기 선택 수 소유
- 런 seed 기반 일반 선택지 생성
- 12종 상한 이후 보유 능력 강화만 제공
- 구슬 종류 선택과 보스 보상은 각각 전용 선택 흐름에 위임

### 12.3 `OrbManager`

- 각 영구 구슬의 종류와 런타임 상태 소유
- 공명, 전도 카운터, 관성, 벽·직접 적중 횟수, 비행 ID 관리
- 회수 원인과 종류별 상태 초기화 규칙 적용
- 영구 직접 타격 event 생성

### 12.4 `TemporaryOrbManager`

- 임시 구슬의 수명, 피해, 충돌, 전체 상한 소유
- 기본 상태에서는 직접 피해 외 효과를 발동하지 않음
- 보스 희귀 보상 예외가 있으면 축소된 발동 권한과 계보 깊이만 보존

### 12.5 `CombatEffectScheduler`

- 기존 지연 전투 효과 정리를 재사용
- 가스 tick, 레이저 수명, 미사일, 충격파 같은 보조 효과 예약과 cleanup
- pause 중 gameplay 시간 정지
- 장면 종료, 패배, 보스 보상에서 예약 효과 정리

### 12.6 직접 타격 해석기

별도 범용 이벤트 버스는 만들지 않는다. `CombatScene`의 기존 충돌 진입점에서 순수 계산 함수에 직접 타격 문맥을 전달한다.

```ts
interface PermanentHitContext {
  orbId: number;
  orbType: OrbType;
  flightId: number;
  targetId: number;
  position: Vector2;
  distanceFromPlayer: number;
  speed: number;
  wallHitsThisFlight: number;
  directHitsSinceWall: number;
  isFirstDirectHit: boolean;
  isPrecisionHit: boolean;
  recoveryCause: RecoveryCause;
}
```

순수 계산 결과는 직접 피해 배율, 상태 변경, 생성할 보조 효과 명령 목록이다. `CombatScene`은 결과를 기존 manager에 적용한다.

### 12.7 중앙 설정

`GAME_TUNING` 아래에 다음 데이터만 둔다.

- 구슬 종류별 기본 수치
- 능력별 최대 등급과 등급 값
- 효과별 확률, 피해, 범위, 지속, 카운터와 cooldown
- 임시 구슬 상한과 계보 제한
- 보스 보상 배율
- 경험치 요구량
- 보스 이동과 보조 피해 감쇠

계산 코드 안에 밸런스 숫자를 중복 작성하지 않는다. ID, 설명, 선택 조건과 수치 표도 가능한 한 같은 정의를 참조한다.

## 13. 데이터 흐름

```text
물리 충돌
→ OrbManager가 영구/임시 구슬과 hit context 구분
→ BuildState와 구슬 고유 상태로 직접 피해 계산
→ EnemyManager 또는 BossManager에 직접 피해 적용
→ 처치 여부 포함한 hit result 반환
→ 영구 직접 타격이면 종류 효과와 일반 발동 판정
→ 보조 효과 명령을 기존 manager에 적용
→ 구슬 상태 갱신과 반사
→ 사망 callback을 한 번만 발생
→ ProgressionManager가 경험치 정산
```

보조 효과는 `source: secondary`로 피해만 전달한다. 따라서 충돌 처리 경로에 다시 들어가지 않는다.

## 14. 오류와 경계 조건

- 존재하지 않는 능력, 구슬 종류, 보스 보상 ID는 시작 시 즉시 오류
- 최대 등급이 0 이하이거나 등급 값 개수가 맞지 않으면 즉시 오류
- 확률은 `0~1`, 시간·거리·피해·속도는 유한한 음이 아닌 값으로 검증
- 시작 구슬은 정확히 3개이며 등록된 종류만 허용
- 추가 구슬 선택으로 6개를 넘길 수 없음
- 구슬 제거·보스 전환 중 예약된 발동은 취소
- 이미 죽은 대상에는 새 직접 타격과 보조 피해를 적용하지 않음
- 같은 피해 사건에서 사망 callback은 한 번만 발생
- 보스의 여러 hitbox가 겹쳐도 같은 effect ID가 같은 파츠를 한 번만 타격
- 임시 구슬 상한에 걸리면 가능한 수만 생성하고 기존 구슬은 제거하지 않음
- pause 중 확률 순번, 지속 시간, cooldown이 진행되지 않음

## 15. 검증

### 15.1 단위 테스트

- 4종 구슬의 중첩, 소모, 회수 원인별 초기화
- 관성 코어가 근접 회수에서만 속도 보너스를 얻고 첫 직접 타격 뒤 종료
- 일반 능력 12종 상한과 기존 능력 등급 상승
- 관련성 조건과 최대 등급 선택지 제외
- 직접 피해 배율과 각 상한
- 효과별 결정적 확률 및 최대 연속 실패
- 한 비행에서 분열 1회
- 임시 구슬의 비재귀 발동과 전체 상한
- 보스 희귀 보상의 축소 발동 및 계보 제한
- 같은 피해 사건의 단일 사망 callback
- 두 번째 보스 반사 파츠 geometry와 영구 노출 이동 경계

### 15.2 브라우저 자동 테스트

- 시작 화면에서 3개 구슬 종류 선택과 중복 선택
- 추가 코어 선택 후 종류 지정과 자동 발사
- 레벨업 12종 도달 뒤 보유 능력 강화만 등장
- 근접 회수, 정밀 직격, 벽 반사, 고속 타격 표시와 실제 피해 일치
- 고정 seed에서 폭발과 분열 발동 순서 재현
- 임시 구슬이 폭발과 분열을 일으키지 않음
- 보스 보상 선택 후 다음 스테이지 재개
- 두 번째 보스 반사 파츠가 구슬을 반사하면서 피해를 받음
- 영구 노출 코어가 이동하고 실제 위치에서 탄환 발사
- pause, 탭 숨김, 패배, 재시작에서 효과와 구슬 상태 정리

### 15.3 직접 플레이

- 첫 레벨업이 너무 즉시 발생하지 않음
- 두 번째 보스 입장까지 일반 선택 8~9회
- 가까이 이동, 벽 전 정밀 타격, 빠른 회수 중 하나 이상을 의도적으로 활용 가능
- 발동 실패가 길게 이어지지 않지만 매 적중 확정처럼 느껴지지 않음
- 분열 단독 획득으로 화면이 즉시 임시 구슬로 포화되지 않음
- 서로 다른 발동 효과가 겹칠 때 강한 순간 정리 쾌감이 생김
- 일반 적 밀도가 높아도 적 탄환과 플레이어 구슬 색을 구분 가능
- 두 번째 보스 파츠 파괴 전후 모두 공격을 피하고 조준할 판단이 존재
- 보스전이 길어져도 코어가 정지한 표적처럼 느껴지지 않음

## 16. 구현 순서

이 설계는 다음 수직 단계로 구현한다.

1. 능력 정의, 12종 상한, 관련성 조건, 중앙 설정
2. 직접 타격 문맥과 비재귀 보조 피해 규칙
3. 기존 폭발·분열을 새 해금·조정 구조로 이관
4. 영구 구슬 4종과 시작·추가 구슬 종류 선택
5. 직접 타격·속도·벽 반사 일반 능력
6. 레이저, 가스, 미사일, 충격파 발동 효과
7. 보스 희귀 보상
8. 두 번째 보스 충돌과 영구 노출 이동 수정
9. 고정 seed 측정 뒤 경험치, 적 체력·밀도, 보스 HP 조정
10. 모바일과 데스크톱 직접 플레이 검증

각 단계는 기존 테스트를 유지하고 해당 단계의 최소 단위·브라우저 검증을 추가한 뒤 다음 단계로 진행한다. 미술과 사운드는 시스템과 밸런스가 안정된 뒤 별도 설계한다.
