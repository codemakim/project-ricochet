# 보스 진입 정리 설계

## 목표

보스 경고 뒤 보스가 기존 일반 적과 겹쳐 생성되는 문제를 없앤다. 기본 보스전은 측면 일반 적을 유지하고, 보스가 들어오는 통로에 있는 최소한의 적만 등장 충격으로 제거한다. 필요하면 중앙 설정 한 값으로 화면 전체 제거 방식으로 바꿀 수 있어야 한다.

이번 작업 전에 현재 실행 경로에서 도달할 수 없는 구형 보스 보상 코드와 명백한 미사용 코드를 삭제한다. 현재 전투 실험용 설정과 그 테스트는 유지한다.

## 범위

### 코드 정리

- 삭제:
  - 호출되지 않는 `selectLegacyBossRewardOptions`
  - 현재 보상 선택기로 획득할 수 없는 구형 1·2차 보스 유물 경로와 그 전용 테스트·튜닝
  - 미사용 E2E fixture
  - `AppController`의 사용하지 않는 템플릿 매개변수
  - `TemporaryOrbManager`의 사용하지 않는 생성자 필드
- 유지:
  - `passThroughOnKill`
  - `homeOnBottomHit`
  - `autoReturnAfterMs`
  - 위 실험 설정의 단위·E2E 테스트
  - 현재 고정·혼합 편대 프리셋과 절차 생성 체계

삭제 뒤 테스트 총개수가 감소하는 것은 정상이다. 숫자를 유지하기 위한 테스트는 추가하지 않는다.

### 보스 진입 처리

지원 모드는 다음 두 개다.

- `corridor`: 기본값. 보스 진입 통로와 겹치는 일반 적만 제거한다.
- `all`: 활성 일반 적을 전부 제거한다.

설정과 여유 폭은 `GAME_TUNING`의 보스 진입 항목에서 한 번만 정의한다. 런타임 메뉴나 URL 옵션은 만들지 않는다.

## 진입 영역

진입 영역은 격자 좌표가 아니라 실제 보스 충돌 형상으로 계산한다.

- Sentinel과 Siege:
  - 초기 X와 `BOSS_GEOMETRY.collisionHalfWidth`를 사용한다.
  - 화면 위쪽부터 초기 보스 충돌 영역의 아래쪽까지를 세로 통로로 잡는다.
- Hive:
  - 초기 코어, 슈터, 리플렉터 형상의 합집합 외곽을 사용한다.
  - 화면 위쪽부터 합집합 외곽의 아래쪽까지를 세로 통로로 잡는다.
- 설정된 여유 폭을 외곽에 더하고 화면 경계로 제한한다.
- `all` 모드는 전체 전장 사각형을 사용한다.

편대 프리셋은 보스 위치를 예약하지 않는다. 현재 적은 계속 부드럽게 하강하고, 보스 경고가 시작된 뒤에는 기존처럼 새 편대가 추가되지 않는다.

## 실행 순서

`bossStarted` 전환을 받은 프레임에서 다음 순서로 처리한다.

1. 보스 종류와 설정 모드로 제거 영역을 계산한다.
2. `EnemyManager`가 실제 활성 물리 바디와 영역이 겹치는 적을 찾는다.
3. 해당 적을 전투 처치가 아닌 진입 정리로 제거한다.
4. 제거된 위치마다 기존 폭발 링 효과를 한 번 표시한다.
5. 보스를 생성한다.

진입 정리로 제거된 적은 다음을 발생시키지 않는다.

- XP
- 보스 진입 점수
- 처치 발동 능력
- 분열 적의 자식 생성
- 돌파 피해

측면에 남은 적은 계속 하강하고 공격한다. Sentinel과 Siege의 기존 수평 이동 장애물 규칙도 그대로 사용한다.

## 코드 경계

- `bossEntryRules`
  - 보스 종류와 정리 모드에서 제거 사각형을 계산하는 순수 규칙
  - 보스별 기존 geometry를 재사용
- `EnemyManager`
  - 영역과 실제 바디가 겹치는 활성 적만 제거
  - 제거된 적의 위치를 반환
  - 기존 `destroyEnemy`를 사용해 타이머와 충돌 상태도 함께 정리
- `CombatScene`
  - `bossStarted`에서 영역 계산, 적 제거, 효과 표시, 보스 생성을 순서대로 조정

새 편대 엔진이나 보스 생성 팩토리는 추가하지 않는다.

## 예외와 경계 조건

- 제거 영역에 적이 없으면 아무 일도 하지 않고 보스를 생성한다.
- 영역 경계에 닿기만 하고 실제로 겹치지 않는 적은 유지한다.
- 여러 칸 적은 실제 바디 일부만 영역에 들어와도 제거한다.
- 슈터 경고 중인 적이 제거되면 해당 경고 타이머도 제거한다.
- 분열 적이 제거되어도 파편은 생성하지 않는다.
- 보스 종류별 형상이 바뀌면 기존 geometry 변경만으로 진입 영역도 따라 바뀐다.

## 테스트

- `bossEntryRules` 단위 테스트:
  - Sentinel/Siege 통로
  - Hive 전체 초기 형상 포함
  - `all` 전체 전장
- `EnemyManager` 단위 테스트:
  - 통로 내부 적 제거
  - 측면 적 생존
  - 다중 칸 적의 부분 교차
  - XP·처치·분열 콜백 미발생
- E2E:
  - 보스 진입 직전 통로와 측면에 적 배치
  - 보스 시작 뒤 통로 적 제거
  - 측면 적 유지
  - 보스와 남은 적의 표시 영역 비중첩

검증은 변경된 단위 테스트, 관련 보스 E2E, 전체 단위 테스트, 타입 검사와 프로덕션 빌드 순서로 수행한다. 전체 E2E는 통합 완료 시 한 번 실행한다.
