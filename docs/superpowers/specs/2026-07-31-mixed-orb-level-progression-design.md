# Project Ricochet 혼합 보상과 기본 구슬 Lv1~Lv5 설계

## 1. 목적

이번 작업은 일반 능력과 구슬 성장을 하나의 레벨업 선택 화면에 섞고, 기본 구슬 6종을 Lv5까지 완성한다.

핵심 목표는 다음과 같다.

- 초반에 구슬 후보를 충분히 제공해 구슬 수를 빠르게 늘릴 기회를 준다.
- 구슬과 일반 능력 중 무엇을 고를지는 플레이어가 결정한다.
- 같은 종류의 구슬도 물리적 인스턴스별로 따로 강화한다.
- 슬롯이 찬 뒤에는 새 구슬 대신 개별 강화가 등장한다.
- 분열·폭발 일반 능력과 전용 구슬이 이중 발동하지 않게 한다.
- 수치와 확률을 중앙 튜닝에서 조정한다.

## 2. 기존 설계와의 관계

이 문서는 `2026-07-31-orb-collection-fusion-redesign.md`의 기본 구슬 성장 원칙을 유지한다.

다음 규칙은 이번 문서가 대체한다.

- 일반 경험치 레벨업과 진행도 기반 핵 보급을 별도 보상으로 나누는 규칙
- 1스테이지와 2스테이지의 강제 구슬 획득
- 슬롯이 찰 때까지 구슬 추가만 제공하는 규칙

진행도 기반 핵 보급 이정표와 전용 보상 큐는 제거한다. `powerBand.expectedOrbCount`는 난도 설계를 위한 기대값으로 유지하며 실제 보유 수를 강제하지 않는다.

융합, 발견, 도감과 시작 구슬 영구 해금 개선은 후속 작업이다.

## 3. 보상 모델

### 3.1 하나의 레벨업 풀

적 처치 경험치로 발생하는 레벨업 하나가 다음 보상을 함께 다룬다.

- 일반 능력 획득 또는 강화
- 구체적인 기본 구슬 Lv1 추가
- 구체적인 보유 구슬 종류 강화
- 후속 작업에서 추가할 구체적인 융합

현재 작업의 보상 타입은 세 개다.

```ts
type RunRewardChoice =
  | { kind: 'ability'; id: AbilityId }
  | { kind: 'orb-add'; coreType: OrbCoreId }
  | { kind: 'orb-upgrade'; coreType: OrbCoreId };
```

후속 융합 작업 전에는 사용하지 않는 융합 타입이나 빈 인터페이스를 미리 추가하지 않는다.

### 3.2 초반 카드 비율

활성 영구 구슬 수에 따라 세 카드의 기본 구성을 정한다.

| 보유 구슬 | 구슬 성장 카드 | 일반 능력 카드 |
| --- | ---: | ---: |
| 1~2개 | 새 구슬 2장 | 능력 1장 |
| 3~5개 | 새 구슬 1장 | 능력 2장 |
| 6개 | 강화 최대 2장 | 능력 최소 1장 |

카드는 항상 세 장을 목표로 하지만 유효 후보가 부족하면 1~2장만 표시할 수 있다. 한 화면에 같은 기본 구슬 종류를 두 번 제안하지 않는다.

초반에 새 구슬 두 종류를 보여줘도 한 번에 얻는 것은 하나뿐이다. 구슬을 고르면 그 레벨업에서 일반 능력을 포기하므로 무료 추가 보상이 아니다.

### 3.3 후보 생성

- 새 구슬 카드는 기본 구슬 6종에서 서로 다른 종류를 결정론적으로 선택한다.
- 이미 가진 종류도 다시 제안할 수 있다.
- 슬롯이 6개면 `orb-add`는 후보에서 제외한다.
- 강화 카드는 보유 중이며 Lv5 미만인 구슬 종류만 제안한다.
- 같은 종류의 강화 카드는 한 장만 제안한다.
- 모든 해당 종류의 구슬이 Lv5면 그 종류의 강화 카드는 제외한다.
- 모든 구슬이 Lv5면 일반 능력만 제안한다.
- 일반 능력과 구슬 후보 선택은 런 시드와 레벨을 사용해 재현 가능해야 한다.

후보 비율은 `GAME_TUNING.rewardFlow`의 구간별 카드 수로 관리한다. 확률과 누락 방지 카운터는 사용하지 않는다.

## 4. 선택 흐름

### 4.1 일반 능력

현재와 동일하다.

1. 카드를 선택한다.
2. 하단 상세 설명을 확인한다.
3. `획득`을 눌러 확정한다.

### 4.2 새 구슬

새 구슬 카드는 결과 종류가 명시된다.

```text
전도 구슬 Lv1
충돌한 적 주변으로 에너지를 전달
```

`획득`을 누르면 해당 종류의 물리 구슬 하나를 Lv1로 추가한다. 별도 종류 선택 화면을 다시 열지 않는다.

### 4.3 개별 강화

강화 카드는 종류를 명시한다.

```text
전도 구슬 강화
보유한 전도 구슬 하나를 Lv1 → Lv2
```

카드를 확정하면 해당 종류의 Lv5 미만 물리 구슬만 표시하는 대상 선택 화면을 연다.

- 각 대상은 슬롯 번호, 종류와 현재 레벨을 표시한다.
- 같은 종류가 여러 개여도 각각 별도 대상이다.
- 대상을 누르면 다음 레벨 효과를 표시한다.
- 두 번째 `강화` 확인을 눌러야 실제 레벨이 오른다.
- 대상이 하나여도 화면은 유지하되 그 대상을 기본 선택한다.
- 대상 확정 전에는 레벨업 보상을 소비하지 않는다.

## 5. 구슬 인스턴스 규칙

- 영구 구슬 슬롯 상한은 6개다.
- 기본 구슬 레벨 범위는 Lv1~Lv5다.
- 새 구슬은 항상 Lv1이다.
- `upgradeOrb(id)`는 선택한 물리 구슬 하나만 한 레벨 올린다.
- 없는 ID, 잘못된 종류 또는 Lv5 구슬은 강화하지 않는다.
- 실패한 선택은 레벨업 보상을 소비하지 않는다.
- 구슬 강화는 현재 비행 상태와 충돌 상태를 유지한다.
- 레벨 상승 직후부터 다음 충돌·틱·회수 판정에 새 레벨을 사용한다.

## 6. 기본 구슬 6종

Lv2와 Lv4는 주 수치를 성장시키고, Lv3와 Lv5는 행동을 바꾼다.

### 6.1 관성

- Lv1: 이동 속도가 빠를수록 직접 피해가 증가한다.
- Lv2: 기본 속도와 속도 피해 상한이 증가한다.
- Lv3: 첫 벽 충돌 전 정밀 직격 시 대상 뒤로 충격파를 낸다.
- Lv4: 정밀 직격 뒤 일정 시간 최고 속도를 유지한다.
- Lv5: 정밀 직격 시 적 하나를 관통하고 최대 두 대상에 운동에너지 폭발을 낸다.

기존의 “직격 누적 뒤 근접 회수 시 다음 발사 가속” 동작은 이 레벨 구조로 대체한다.

### 6.2 전도

- Lv1: 직접 충돌 시 가까운 적에게 연쇄 공격한다.
- Lv2: 전달 거리와 대상 수가 증가한다.
- Lv3: 비행 중 가까운 적 하나를 약한 에너지선으로 지속 공격한다.
- Lv4: 비행 공격의 대상 수와 틱 속도가 증가한다.
- Lv5: 직접 충돌 시 현재 연결 중인 모든 적에게 과충전 피해를 준다.

### 6.3 분열

- Lv1: 직접 충돌 시 일정 확률로 임시 구슬 2개를 만든다.
- Lv2: 분열 확률이 증가한다.
- Lv3: 임시 구슬이 벽 또는 적에게 한 번 더 튕길 수 있다.
- Lv4: 임시 구슬 수와 유지 시간이 증가한다.
- Lv5: 임시 구슬이 허용된 공용 공격 효과를 낮은 효율로 계승한다.

임시 구슬은 재분열하지 않는다. 계승 가능한 효과는 명시적 허용 목록으로 제한한다.

### 6.4 부식

- Lv1: 직접 충돌 시 일정 확률로 고정 부식 지역을 만든다.
- Lv2: 부식 지역 범위와 지속 시간이 증가한다.
- Lv3: 첫 벽 충돌 전 정밀 직격한 적에게 이동식 부식 지역을 붙인다.
- Lv4: 부식 중첩이 적의 받는 피해를 증가시킨다.
- Lv5: 부식된 적이 죽으면 주변에 작은 부식 지역을 확산한다.

### 6.5 반향

- Lv1: 벽 충돌마다 공명을 저장하고 다음 직접 충돌 피해를 높인다.
- Lv2: 공명 상한과 중첩당 피해가 증가한다.
- Lv3: 저장한 공명을 방출할 때 작은 충격파를 낸다.
- Lv4: 벽 충돌 시 낮은 확률로 수평 또는 수직 절단선을 낸다.
- Lv5: 최대 공명 방출 시 직전 반사 경로를 따라 공명파를 재생한다.

### 6.6 폭발

- Lv1: 직접 충돌 시 일정 확률로 폭발한다.
- Lv2: 폭발 피해가 증가한다.
- Lv3: 연속 실패할 때마다 다음 폭발 확률이 증가한다.
- Lv4: 폭발 범위가 증가한다.
- Lv5: 실패 누적이 최대가 되면 중심부 고위력 폭발을 일으킨다.

## 7. 일반 폭발·분열 능력과의 결합

일반 `충격 폭발`과 `분열 프로토콜`은 유지한다.

- 다른 종류의 구슬은 일반 능력으로 기존 폭발·분열을 해금한다.
- 폭발 구슬과 분열 구슬은 자신의 고유 효과를 능력 없이 사용한다.
- 전용 구슬이 같은 일반 능력을 얻어도 독립된 두 번째 판정을 굴리지 않는다.
- 고유 프로필 하나에 전용 시너지 보너스를 합친 뒤 한 번만 판정한다.

결합 순서는 다음과 같다.

1. 구슬 종류와 레벨로 고유 프로필을 계산한다.
2. 해당 일반 능력이 있으면 중앙 튜닝의 시너지 보너스를 합친다.
3. `발동 최적화`, `효과 출력`, `영향권 확장`, 파편 강화 등 공용 보정을 적용한다.
4. 최종 확률 판정을 한 번 실행한다.

폭발 시너지의 확률 보너스·피해 배율과 분열 시너지의 확률 보너스·추가 구슬 수는 `GAME_TUNING.orbCores`에 둔다.

## 8. 코드 경계

### 8.1 구슬 정의와 튜닝

- `OrbCoreId`에 `split`, `explosion`을 추가한다.
- 기본 구슬 이름, 요약과 최대 레벨은 하나의 코어 정의에서 UI가 읽는다.
- 레벨별 확률, 피해, 범위, 대상 수, 틱, 지속 시간과 상한은 `GAME_TUNING.orbCores`에 둔다.
- 각 레벨 배열은 정확히 5개 값을 가지며 시작 시 검증한다.
- `docs/TUNING.md`에 새 조정 위치를 추가한다.

### 8.2 순수 규칙

`orbCoreRules`는 다음 입력만 받아 결과를 계산한다.

- 구슬 종류
- 현재 레벨
- 구슬별 런타임 상태
- 충돌·벽 반사·회수·비행 틱 문맥
- 공용 능력 보정

결과는 직접 피해 보너스, 발동 여부, 대상 수, 생성할 효과와 다음 상태다. Phaser 객체, 적 매니저와 시각 효과를 직접 소유하지 않는다.

### 8.3 전투 실행

기존 전투 계층은 순수 결과를 받아 다음만 수행한다.

- 적·보스 피해 적용
- 임시 구슬 생성
- 부식 지역 생성·부착·확산
- 연쇄선·지속 연결선·충격파·절단선 렌더링
- 관통과 반사 경로 처리

구슬별 클래스, 범용 효과 DSL과 외부 JSON 로더는 만들지 않는다.

## 9. 레벨업 상태와 일시정지

- `ProgressionManager`는 혼합 보상 후보와 미결 선택을 저장한다.
- 2차 대상 선택이 필요한 강화는 마지막 확인 뒤에만 선택을 소비한다.
- 상태가 바뀌어 대상이 무효가 되면 후보를 다시 계산하고 화면을 유지한다.
- 보상 화면에서는 전투 시간이 진행되지 않는다.
- 한 보상이 끝난 뒤 기존 `GAME_TUNING.rewardFlow.resumeGameplayMs`만큼 전투를 재개한다.
- 여러 레벨업이 대기하면 같은 혼합 보상 흐름을 반복한다.

별도 `pendingCoreSupplies`, 진행도 핵 보급 우선순위와 핵 보급 전용 일시정지 흐름은 제거한다.

## 10. 시각 피드백

실제 아트 제작은 범위 밖이지만 플레이테스트 구분은 제공한다.

- 여섯 기본 구슬은 서로 다른 색과 내부 기호를 사용한다.
- 레벨은 구슬 외곽 링 또는 작은 노치 수로 구분한다.
- Lv3와 Lv5 행동 발동은 기존 일반 능력과 구별되는 색·선·폭발 형태를 사용한다.
- 적 탄환 색과 혼동되는 보라·적색 단색 투사체는 피한다.
- 강화 대상 화면에서 실제 슬롯 순서와 구슬 색을 유지한다.

## 11. 경계 조건

- 보상 생성과 확정 사이에 슬롯이 차면 새 구슬 확정을 거부하고 후보를 다시 계산한다.
- 선택한 강화 대상이 사라지거나 Lv5가 되면 확정을 거부하고 대상을 다시 표시한다.
- 같은 물리 구슬을 한 보상으로 두 번 강화하지 않는다.
- 슬롯 6개를 초과하지 않는다.
- 존재하지 않는 구슬 ID, 잘못된 레벨 배열과 범위 밖 레벨은 시작 시 오류로 처리한다.
- 보스 파츠 겹침으로 한 효과가 같은 파츠를 중복 타격하지 않는다.
- 임시 구슬과 지속 효과는 중앙 동시 상한을 지킨다.

## 12. 검증

### 12.1 단위 테스트

- 보유 1~2개에서 구슬 2장·능력 1장
- 보유 3~5개에서 구슬 1장·능력 2장
- 보유 6개에서 새 구슬 제외와 강화 후보 생성
- 같은 화면의 구슬 종류 중복 방지
- 같은 종류 여러 개 중 선택한 인스턴스 하나만 강화
- Lv5 대상 제외와 모든 구슬 Lv5 시 능력 대체
- 여섯 구슬의 Lv1~Lv5 행동 계약
- 일반 폭발·분열과 전용 구슬의 단일 판정
- 레벨별 중앙 튜닝 검증

### 12.2 브라우저 테스트

- 첫 레벨업에 서로 다른 구슬 2장과 능력 1장 표시
- 구슬 카드 선택 후 해당 Lv1 구슬 추가
- 세 번째 구슬 이후 구슬 카드가 한 장으로 감소
- 여섯 슬롯에서 새 구슬 대신 강화 카드 표시
- 중복 종류 중 하나를 골라 개별 강화
- 모바일에서 카드 선택, 상세 확인, 대상 선택과 최종 확인
- Lv3와 Lv5의 대표 전투 효과를 실제 충돌로 확인

전체 Playwright 회귀는 기능 묶음 끝에 한 번 실행한다. 내부 규칙 작업마다 브라우저 전체를 반복하지 않는다.
