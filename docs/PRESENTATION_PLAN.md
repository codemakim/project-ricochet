# 출시 표현 완성 계획

## 2026-10-14 승인된 PC 방향

- PC 키보드·마우스를 우선 제작 기준으로 삼는다.
- 저해상도 픽셀 제약을 풀고, 우주 속 인공 전장과 매끈한 현대적 기체로 통일한다.
- 넓은 장갑면과 핵의 형태로 구분한다. 잔문양·외계 종족·고대 석상 같은 장식은 제외한다.
- 구슬은 작은 선명한 핵과 절제된 빛 테두리, 종류별 핵 구조·움직임으로 개성을 만든다.
- 첫 적용 묶음: 배경·플레이어·기본 적·폭발/분열/부식 구슬·부식 입자장.
- 아래 픽셀 제작 완료 기록은 이전 방향의 기록이다. 상용 품질 승인으로 취급하지 않는다.

## 제작 기준

- 대표 시안은 `assets-source/combat/pc/masters/concept.png`, 제작/출력 기준은 같은 폴더의 상위 `README.md`를 따른다.
- 현재 전투 규칙, 보스 파츠 구성, 충돌 영역과 밸런스는 유지한다.
- 아래 표현 작업이 끝나기 전에는 새 보스나 스테이지를 추가하지 않는다.

## 현재 미완성 범위

- 세 보스 정식 픽셀 아트는 2026-09-10 완료했다.
- 전투 사운드·음악 1차 방향은 2026-09-14 사용자 승인. 전체 런의 음량·반복 피로도 검수는 남았다.
- VFX 36종 모두 정식 원화 기반 8프레임 시트로 교체했다. 기하 도형 임시 시트 17종은 제거했고, 최종 시각 승인은 남았다.
- 시트 교체 뒤 남아 있던 독·나노·클러스터·융해 장판과 분열 자탄의 도형 표현을 2026-09-16 실제 렌더 경로에서 교체했다. 독·분열·폭발은 데스크톱·모바일의 실제 구슬 충돌로 확인했다.
- HUD·조작 안내·음소거를 전장 밖으로 분리했고 반복 VFX 광량과 적 공격 레이어를 1차 조정했다.
- 출격, 레벨업, 보스 보상과 메타 화면은 텍스트 중심 프로토타입 표현이다.

## 작업 순서

1. **보스 정식 픽셀 아트 — 완료**
   - 기존 `boss-family.png`를 기준으로 Sentinel을 먼저 제작해 실제 전투 크기로 승인한다.
   - 승인된 규칙으로 Hive와 Siege를 제작한다.
   - 파괴 가능한 모든 파츠를 분리하고 기존 표시 크기와 충돌 영역을 유지한다.
2. **전투 사운드 수직 슬라이스 — 1차 방향 승인, 전체 런 청감 검수 대기**
   - 발사, 회수, 반사, 직격, 파괴, 경고, 피격과 보스 상태 SFX를 연결한다.
   - 일반 전투 음악과 동기화된 보스 레이어, 음소거, 브라우저 오디오 해제를 구현한다.
   - 효과음 16종, 32초 음악 2레이어, 저장되는 음소거 버튼·M 키, 선택창 감쇠와 탭 복귀를 연결했다.
   - `assets-source/combat/audio/combat-preview.wav`로 음색을 확인하고 전체 런에서 피로도를 검수한다.
3. **전투 표현 마감 — 실전 연결 보완, 최종 시각 승인 대기**
   - 완료: 전장 밖 DOM HUD·조작 안내·44px 음소거 버튼, 중앙 정렬, HP·XP·보스 체력.
   - 완료: 발사·회수·직격 등 반복 VFX 축소·단축·감광, 적 공격을 VFX 위로 표시, 전체 화면 피격 섬광을 HUD 반응으로 교체.
   - 완료: 보스 이름·진입 진행률 경고, 420ms 진입 페이드, 방어 부위·코어 상태 HUD, 모든 피해 경로의 부위 파괴·코어 노출 효과.
   - 완료: 900ms 격파 효과가 끝난 뒤 레벨업·보상·최종 결과로 전환한다. 격파 중 전투는 정지하고 숨긴 탭에서는 효과도 정지한다.
   - 완료: 선택창에서 제작 VFX는 재생을 마치고 제거되며, 순간 선·피해 숫자는 즉시 정리한다. 세 보스·320px 화면·탭 복귀·재시작을 검증했다.
   - 완료: 임시 VFX 17종을 현상별 원화와 8프레임 시트로 교체했다. 기존 수명·크기·광량·동시 상한과 전투 규칙은 유지한다.
   - 보완: 지속 장판 4종을 게임 시간에 맞춰 정식 시트로 반복 재생하고, 분열·공명 자탄에 해당 구슬 원화를 사용한다. 독 부착 위치 갱신과 패배·보상 전환의 장판 정리도 보완했다.
   - 보완: 광자·거울의 지속 선을 제작 빔으로 바꾸고, 광자·벡터 순간 효과를 피해 선분의 중심·방향·길이에 맞췄다. 클러스터 제작 탄체는 실제 이동·도착·정지·제거 경로에 연결했다.
   - 실제 충돌·지속 효과 검증 캡처: `output/playwright/live-core-vfx/`, `output/playwright/live-core-vfx-mobile/`, `output/playwright/live-field-vfx/`. 시트 미리보기 검증과 구분한다.
   - 원화·프롬프트는 `assets-source/combat/vfx-masters/`, 보스 전환 캡처는 `output/playwright/boss-transitions/`, 마지막 VFX 캡처는 `output/playwright/authored-vfx-final-verified/`에 보존했다.
   - 사용자에게 보스 전환 방향을 승인받았고, 마지막 VFX 화면의 시각 승인 후 4단계로 진행한다.
4. **선택·메타 UI 개편**
   - 출격 구슬, 레벨업, 보스 보상을 이미지 카드로 바꾼다.
   - 작업장, 결과 화면과 글꼴·패널 언어를 전투 아트에 맞춘다.
5. **통합 출시 검수**
   - 모바일·데스크톱 전체 런에서 시각 가독성, 사운드 피로도, VFX 혼잡도와 전투 압력을 확인한다.
   - 이 검수 뒤에도 혼합 해상도가 부자연스러울 때만 아트 방향 변경을 검토한다.

각 단계는 대표 화면 또는 음원을 승인한 뒤 다음 단계로 진행한다.
